# Layout Guide

**Purpose:** Choose layout structures from content and task, not from habit.

## Grid defaults

- Desktop: 12 columns, 1200-1320px max content width, 24-32px gutters.
- Tablet: 8 columns. Mobile: 4 columns, 16-20px side margins.
- Reading content: single column at 60-75 characters, even on wide screens.

## Choose a pattern by content

| Content | Pattern that usually fits | Watch out for |
|---|---|---|
| One main message and action | Asymmetric hero with text and one strong image | Centered text over stock photo |
| Parallel items of equal weight (plans, products) | Card grid | Using cards for non-parallel ideas |
| Sequential process | Numbered vertical list or timeline | Icons in circles with no numbers |
| Long explanation | Editorial column with pull-outs | Breaking text into many tiny cards |
| Comparison | Table | Comparison hidden in carousels |
| Mixed proof (cases, quotes) | Varied module sizes by importance | Identical carousel slides |

## Rhythm

Vary section height and structure based on importance. A page where every section has the same padding and layout reads as a template.

## Common mistakes

- Full-width text lines on desktop.
- Carousels for important content. Many users never see slide two.
