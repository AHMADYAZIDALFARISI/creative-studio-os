# Typography Guide

**Purpose:** Choose and set type that serves the brand and reads well.

## Selection steps

1. Start from the brand personality traits. Write which trait each candidate typeface expresses.
2. Check script coverage: Latin extended at minimum. Add other scripts if the client needs them.
3. Check weights you need (usually 2-4), italics, tabular numbers for data, and web license terms and cost.
4. Test with real content: long Indonesian words, prices, headlines at mobile width.
5. Define a fallback stack that matches metrics closely to limit layout shift.

## Default rules

- Body 16-18px on web, line height 1.4-1.6, line length 60-75 characters.
- Use a type scale with clear steps. Ratios of 1.2-1.333 suit dense interfaces; 1.333-1.5 suit editorial pages.
- Maximum two families in most projects. A mono face for data counts as a third only when it has a job.
- Use tabular figures in tables and prices.
- Do not set body text in light weights below 400 on screen.

## When Inter or a system font is right

Interfaces where neutrality, performance, and data density matter more than voice, such as internal admin tools. Write that reason in the creative brief. Do not use it by habit on brand-led sites.

## Common mistakes

- Choosing a display face that fails at small sizes, then using it for buttons.
- Loading eight weights and using three.
