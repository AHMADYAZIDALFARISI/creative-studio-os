# Glossary

| Term | Meaning in this studio |
|---|---|
| Acceptance criteria | Testable conditions the client agrees define "done" for a deliverable. |
| Anti-slop audit | Our checklist for generic, unjustified, or fabricated output. |
| Creative direction | A documented visual and verbal concept tied to a business reason. |
| Design token | A named value (color, space, type size) used by both design and code. |
| Direction | One of two or three distinct visual approaches explored before approval. |
| Evidence label | [Client], [Verified], [Hypothesis], or [Recommendation]. Defined in the discovery process. |
| Gate | A checkpoint that must pass before the next stage starts. |
| Handoff kit | Inventory of screens, components, tokens, states, and notes for developers. |
| Hypothesis | A belief we have not verified. It needs a test or client confirmation. |
| Scope creep | Work added without a change request. |
| Stitch | Google Stitch, an AI UI generation tool from Google Labs. We use it for exploration. |
| SOW | Scope of Work: deliverables, exclusions, assumptions, timeline, acceptance. |
| State | A UI condition: default, loading, empty, error, success, disabled. |
| Studio OS | This repository. |
