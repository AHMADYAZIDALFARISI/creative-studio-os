# Status Updates and Meeting Notes

**Purpose:** Keep clients informed with a predictable format.
**Cadence:** Weekly status by default; within 24 hours after every meeting.

## Weekly status: English

```
Subject: {{PROJECT}} status, week of {{YYYY-MM-DD}}

Overall: On track / At risk / Off track
Reason (if not on track): {{ONE_SENTENCE}}

Done this week
- {{ITEM}}

Next week
- {{ITEM}}

Waiting on you
- {{ITEM}}, needed by {{DATE}} {{TIMEZONE}}. Impact if late: {{IMPACT}}

Risks
- {{RISK}}: {{MITIGATION}}
```

## Laporan mingguan: Bahasa Indonesia

```
Subjek: Status {{PROYEK}}, minggu {{YYYY-MM-DD}}

Status umum: Sesuai jadwal / Berisiko / Terlambat
Alasan (jika tidak sesuai jadwal): {{SATU_KALIMAT}}

Selesai minggu ini
- {{ITEM}}

Minggu depan
- {{ITEM}}

Menunggu dari Anda
- {{ITEM}}, dibutuhkan paling lambat {{TANGGAL}} WIB. Dampak jika terlambat: {{DAMPAK}}

Risiko
- {{RISIKO}}: {{MITIGASI}}
```

## Meeting notes (EN/ID)

```
Meeting / Rapat: {{TITLE}} | {{YYYY-MM-DD}} {{TIME}} {{TIMEZONE}}
Attendees / Peserta: {{NAMES}}

Decisions / Keputusan
1. {{DECISION}}

Action items / Tindak lanjut
| Action | Owner | Due |
|---|---|---|

Open questions / Pertanyaan terbuka
- {{QUESTION}}

Please reply within {{N}} working days if anything is incorrect.
Mohon balas dalam {{N}} hari kerja jika ada yang tidak sesuai.
```

## Rules

- Decisions made by chat or call get confirmed in writing in the next status.
- "Waiting on you" always includes a date and an impact.
