# Reference Evaluation

**Purpose:** Learn principles from references without copying them.
**Use when:** Building moodboards and creative directions.

## Rules

- Collect references from outside the client's category as well as inside it.
- For every reference, write what principle it teaches. A reference without a note gets removed.
- Never trace, rebuild, or prompt Stitch to "make it like {{BRAND}}".
- Store reference images in the private project folder with source URL and date.

## Common mistakes

- Moodboards of attractive images with no stated principle.
- Choosing references only from award galleries. They reward novelty, not the client's users.
