# Brand Identity System

**Purpose:** Build a brand system that works across digital touchpoints and survives handoff.
**Use when:** The project includes new identity work or a refresh of an existing one.
**Inputs:** Approved positioning, creative direction, existing assets.
**Output:** Brand guideline document and an asset package.

## Components and minimum deliverables

| Component | Minimum deliverable | Key decision to document |
|---|---|---|
| Logo | Primary, secondary/compact, symbol; SVG + PNG; light and dark versions | Clear space, minimum size (digital in px, print in mm), forbidden uses |
| Typography | One to two families with licenses confirmed | Why these faces fit the personality; fallback stack; web licensing |
| Color | Core palette with roles, tested contrast pairs | Which pairs are allowed for text; dark mode mapping if needed |
| Image direction | 6-10 approved reference images with notes | Subject, light, framing, retouching, what to avoid |
| Illustration | Style rules and two examples, if used | Line weight, color use, level of detail |
| Iconography | Icon set choice or rules for custom icons | Stroke, grid, corner style, size steps |
| Graphic elements | Patterns or shapes derived from the concept | Where they appear and where they never appear |
| Composition and grid | Grid for web and social formats | Margins, columns, alignment rules |
| Tone of voice | Traits with is/is not, sample lines in EN and ID | Formality level per channel |
| Digital applications | Website header, social post, email signature, favicon | How the system scales down |

## Process

1. **Concept.** Write the visual concept in two sentences that link to the positioning.
2. **Explore.** Produce two or three distinct routes. Each route differs in idea, not only in color.
3. **Test.** Place each route on real touchpoints: favicon at 16px, mobile header, social avatar, invoice.
4. **Refine.** Develop one route. Check legibility, contrast, and reproduction.
5. **Systematize.** Write rules with correct and incorrect examples.
6. **Hand off.** Package files with a naming convention: `{{brand}}-logo-primary-dark.svg`.

## Accessibility

- Logo needs a text alternative pattern for web (`aria-label` or visible brand name).
- Every text color pair in the palette lists its contrast ratio.
- Do not rely on color alone to carry meaning in brand graphics.

## Originality rules

- Do not copy or closely imitate another brand's mark, wordmark, or signature graphic.
- Run a basic visual search on the final mark and record the date. This is not a legal trademark clearance. Advise the client to use a trademark professional for clearance.

## Common mistakes

- Presenting three routes that are the same idea in three colors.
- Choosing a typeface without checking web license cost.
- Delivering only a PDF guideline with no source files.
